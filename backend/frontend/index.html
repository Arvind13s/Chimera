About the Project

Chimera is an ambitious, open-source multi-agent orchestration framework designed for fully autonomous short-form video production. Inspired by the mythological Chimera—a single entity composed of diverse, powerful parts—this project unites six specialized AI agents into one cohesive pipeline.

The pipeline is engineered to require zero human intervention post-prompt. Simply provide a topic, and the system dynamically researches the niche, scripts a compelling narrative, synthesizes professional voiceovers, sources relevant stock footage, generates a matching soundtrack, and seamlessly stitches it all together using programmatic video editing.

Built with modern technologies including FastAPI for the robust backend, Groq LLMs for lightning-fast inference, Edge-TTS for realistic vocal synthesis, and a custom MoviePy engine for precise timeline assembly.
